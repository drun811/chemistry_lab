# 🧪 Алхимик: Интерактивная химическая лаборатория

Обучающая мини-игра по химии для школьников. Смешивай вещества, наблюдай за реакциями и открывай новые элементы!

> ⚠️ **Важное предупреждение:** Это симуляция. Не пытайтесь повторять эти реакции в реальной жизни без присмотра учителя или лаборанта.

## ✨ Возможности
- **Интерактивные реакции:** Более 10 химических превращений с анимацией и звуками.
- **Система прокачки:** Получай опыт за новые открытия и повышай уровень.
- **Энциклопедия:** Вещества открываются по мере их получения в игре.
- **Автосохранение:** Прогресс сохраняется в браузере (localStorage).

## 🧪 Как играть
1.  Кликни на две бутылки с веществами на полке.
2.  Они появятся в слотах над колбой.
3.  Нажми «Провести реакцию 🔥».
4.  Смотри на результат: цвет жидкости, эффекты (вспышка, шипение) и уравнение реакции.

## 📂 Структура проекта
Весь проект упакован в один файл `index.html` (HTML + CSS + JS), чтобы его было легко запустить.
